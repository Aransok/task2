# SoftUniBazar

An ASP.NET Core MVC marketplace/bazaar application — course project for SoftUni.

## Structure
- `SoftUniBazar/` — ASP.NET Core MVC web app
- `SoftUniBazar.Data/` — data layer / EF Core models

## Tech Stack
- ASP.NET Core MVC
- Entity Framework Core

## Getting Started
Open `SoftUniBazar.sln`, restore packages, update the connection string, and run.
